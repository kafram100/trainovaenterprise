# AGENT.md

# Trainova Enterprise Web Platform

## Project Overview

Trainova Enterprise is a modern educational technology ecosystem focused on building intelligent digital infrastructure for education across Africa.

The platform combines:
- educational software
- school infrastructure systems
- AI-powered assessment platforms
- educational media
- practical technology training

The system must feel:
- modern
- minimal
- scalable
- premium
- educational
- intelligent

This is NOT a generic corporate website.

The platform should communicate:
> “Trainova is building the future infrastructure of education in Africa.”

---

# Brand Meaning

Trainova = Training + Innovation

Official tagline:
> “Training People to Innovate.”

# Design System

## Design Philosophy

The interface must be:
- minimal
- modern
- fast
- clean
- educational
- responsive
- elegant

Avoid:
- clutter
- excessive gradients
- old-school layouts
- overly colorful UI
- crowded sections

---

# UI Style

Preferred UI direction:
- Apple-inspired spacing
- modern SaaS layout
- soft shadows
- subtle glassmorphism only when necessary
- rounded corners
- large typography
- dashboard-style sections
- modern cards
- smooth animations

---

# Theme & Color System

Color tokens, theme variables, and design tokens will be provided separately.

DO NOT hardcode colors in components.

Use:
- CSS variables
- theme tokens
- reusable design tokens
- centralized theming architecture

The design system must support:
- easy rebranding
- theme scalability
- future dark/light modes
